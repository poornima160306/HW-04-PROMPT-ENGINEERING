Python Programs This repository contains three simple Python programs that demonstrate basic programming concepts and the translation of C programs into Python.

Files 1.⁠ ⁠factorial.py Calculates the factorial of a number using a for loop.

2.⁠ ⁠fibonacci.py Generates and displays a Fibonacci sequence for the number of terms entered by the user.

3.⁠ ⁠structure.py Uses a Python class to store and display student information. This program is translated from a C struct.

Requirements Python 3 No external packages are required. Only the Python standard library is used. How to Run Open a terminal in the repository folder and run:

python factorial.py python fibonacci.py python structure.py Purpose The purpose of these programs is to understand basic Python programming and compare Python with equivalent C programs, especially in areas such as loops, input/output, and data structures.
